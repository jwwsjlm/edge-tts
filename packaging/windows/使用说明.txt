Edge TTS HTTP Server - Windows 本地双击版
============================================

这个文件夹可直接在 Windows x64 电脑上运行：无需安装 Python、Docker 或执行 pip install，启动时无需联网安装依赖。语音合成仍需能访问微软 TTS 上游。

先看这四个文件
--------------

1. 01-双击启动服务.bat
   双击它会启动 edge-tts-server.exe。服务运行期间不要关闭弹出的窗口。

2. 02-打开接口文档.url
   服务启动后双击它，打开 Swagger 接口文档。

3. 03-本地调用示例.ps1
   服务启动后运行它，会生成 speech.mp3。

4. config.yaml
   首次启动时自动创建，里面保存 API Key 和端口配置。不要把 api_key 发给其他人。

快速开始
--------

1. 双击 01-双击启动服务.bat。
2. 第一次启动会在当前目录创建 config.yaml，并自动生成随机 API Key。
3. 双击 02-打开接口文档.url，或访问：http://127.0.0.1:5050/docs
4. 健康检查地址：http://127.0.0.1:5050/health

默认只允许本机访问：

    host: "127.0.0.1"
    port: 5050

不要把 host 改成 0.0.0.0，除非你明确需要让局域网其他设备访问。

调用示例
--------

在本文件夹打开 PowerShell，执行：

    powershell -ExecutionPolicy Bypass -File .\03-本地调用示例.ps1 -Text "你好，世界"

脚本会从 config.yaml 读取 api_key，通过 X-API-Key 请求头调用服务，并生成 speech.mp3。

音色、字幕与代理
--------------

带 X-API-Key 调用 /v1/voices?locale=zh-CN 可查询音色；把返回的 name 用于 /v1/tts 或 /v1/tts/bundle。Bundle 的 boundary 可选 WordBoundary 或 SentenceBoundary，下载 ZIP 固定只含 speech.mp3 和 speech.srt。

proxy 是服务访问微软上游的全局 HTTP/HTTPS 代理，只能在 config.yaml 配置，不能由客户端请求传入。不要公开包含账号密码的代理地址。
